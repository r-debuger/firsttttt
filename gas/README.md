# 線上訂單串接 Google Sheet（Google Apps Script）

網站的結帳表單送出後，訂單會寫進 Google 試算表，並寄信通知店家（顧客有填 Email 時也會收到確認信）。

```
網站結帳表單 ──POST JSON──▶ Apps Script 網頁應用程式 (gas/Code.gs) ──▶ Google 試算表
                                         └──▶ Gmail：店家通知信、顧客確認信
```

## 一、建立試算表與程式（約 5 分鐘）

1. 到 Google 雲端硬碟新增一份 **Google 試算表**，命名例如「餃個朋友 訂單」。
2. 在試算表上方選單點 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的程式碼，把本資料夾的 `Code.gs` 全部內容貼上，按 **儲存**（磁碟圖示）。
4. 上方函式下拉選單選 **`setup`**，按 **執行**。
   - 第一次會要求授權：選擇您的 Google 帳號 → 「進階」→「前往（專案名稱）」→「允許」。
   - 授權內容包含：編輯這份試算表、以您的名義寄信（用於訂單通知）。
5. 回到試算表，會看到自動建立的四個工作表：

| 工作表 | 用途 |
| --- | --- |
| **訂單** | 每筆訂單一列：編號、時間、狀態、取餐方式、顧客資料、品項摘要、金額。「狀態」欄有下拉選單（新訂單／製作中／可取餐／已出貨／已完成／已取消）。 |
| **訂單明細** | 每個品項一列，方便用樞紐分析統計銷量。 |
| **商品** | 商品 ID、名稱、**價格**、是否供應中。訂單金額一律以這裡的價格在伺服器重新計算。 |
| **設定** | 店家通知信箱、是否寄顧客確認信、宅配運費與免運門檻、暫停接單。 |

## 二、部署為網頁應用程式

1. Apps Script 編輯器右上角 **部署 → 新增部署作業**。
2. 「選取類型」齒輪 → **網頁應用程式**。
3. 設定：
   - **執行身分：我**
   - **具有存取權的使用者：所有人**（網站訪客不需登入 Google 就能下單）
4. 按 **部署**，複製「網頁應用程式網址」（格式：`https://script.google.com/macros/s/……/exec`）。
5. 用瀏覽器打開這個網址，看到 `{"ok":true,"service":"gyo-friends-orders","open":true}` 就代表成功。

## 三、把網址填進網站

打開 `index.html`，搜尋 `ORDER_API_URL`，把網址貼進引號中：

```js
const ORDER_API_URL='https://script.google.com/macros/s/……/exec';
```

填入後網站自動切換為正式接單：按鈕變成「送出訂單」，成功畫面顯示正式訂單編號（例如 `GF-20261127-001`），並隱藏「展示網站」的提示文字。網址留空時維持原本的展示模式，不會送出任何資料。

## 日常營運

- **改價格／停售商品**：直接改「商品」工作表的價格，或把「供應中」改為「否」。網站上的價格寫在 `index.html` 的商品清單，記得兩邊一起改；若不一致，訂單以試算表價格為準，成功畫面也會顯示試算表算出的總金額。
- **宅配運費**：在「設定」填入運費與免運門檻（預設 0，不收運費）。網站送出前不會預先顯示運費，成功畫面與確認信會列出實際金額。
- **暫停接單**（公休、備料不足）：「設定」的「暫停接單」改為「是」，顧客送出時會看到「目前暫停線上接單，請直接致電門市」。
- **通知信**：預設寄給部署者本人；可在「設定」填其他信箱（多個以逗號分隔），填「無」則不寄。Gmail 一般帳號每天約可寄 100 封。

## 修改程式後要重新部署

改了 `Code.gs` 之後，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不變、網站不用改。若選「新增部署作業」會產生新網址，就需要重新填入 `index.html`。

## 安全機制

- 前端傳來的價格一律忽略，金額由試算表價格重新計算。
- 同一支電話 10 分鐘內最多 5 筆訂單；表單含隱藏的防機器人欄位。
- 寫入試算表的文字若以 `=` `+` `-` `@` 開頭會自動加上單引號，避免公式注入；電話以文字儲存，不會掉開頭的 0。
- 使用 LockService 確保同時下單時訂單編號不重複。
- 試算表本身只有您能存取；網頁應用程式只開放「新增訂單」與健康檢查，不會回傳任何既有訂單資料。

## 注意事項

- 本串接只處理「下單」，不含線上付款；付款方式請於電話確認時與顧客約定。
- 訂單含顧客個資（姓名、電話、地址），請勿將試算表設為公開分享。
